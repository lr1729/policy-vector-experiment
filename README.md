# Policy Vector Extraction

Clean implementation for extracting the "off-policy detection" direction from reasoning models.

## Overview

This pipeline extracts a vector that captures what makes reasoning "off-policy" (not naturally generated by the model) vs "on-policy" (natural model output). The key insight: by paraphrasing sentences while preserving semantics, we can isolate **syntactic/statistical naturalness** from semantic content.

## Quick Start

```bash
# 1. Generate natural on-policy rollouts
python 01_generate_on_policy.py --num-rollouts 5

# 2. Paraphrase sentences with 3 models
export OPENROUTER_API_KEY='your-key-here'
python 02_paraphrase_sentences.py --max-workers 40

# 3. Create off-policy variants with span-clipping
python 03_create_off_policy.py --variants-per-rollout 10

# 4. Extract vector
python 04_extract_vector.py
```

## Pipeline Details

### 1. Generate On-Policy Rollouts
```bash
python 01_generate_on_policy.py \
    --prompts data/prompts.json \
    --num-rollouts 5 \
    --model Qwen/Qwen3-4B
```

**What it does:**
- Loads prompts from persona vectors dataset
- Generates reasoning rollouts with thinking enabled
- Stores complete raw output with all special tokens
- Default: 40 prompts × 5 rollouts = 200 samples

**Key parameters:**
- `--max-prompts`: Limit number of prompts (default: all)
- `--num-rollouts`: Rollouts per prompt (default: 10)

### 2. Paraphrase Sentences
```bash
python 02_paraphrase_sentences.py \
    --max-workers 40 \
    --checkpoint-every 100
```

**What it does:**
- Extracts unique sentences from rollouts
- Filters out non-paraphraseable content (---, $$, bold labels)
- Paraphrases each sentence with 3 models independently
- Saves checkpoint every 100 completions

**Models used:**
- `openai/gpt-5-mini`
- `deepseek/deepseek-chat`
- `anthropic/claude-3.5-haiku`

**Key parameters:**
- `--max-workers`: Parallel API requests (default: 30)
- `--checkpoint-every`: Checkpoint frequency (default: 100)

**Output:** `data/sentence_paraphrases.json` - lookup table mapping sentences to paraphrases

### 3. Create Off-Policy Variants
```bash
python 03_create_off_policy.py \
    --variants-per-rollout 10 \
    --seed 42
```

**What it does:**
- For each rollout, creates multiple off-policy variants
- **Uniform distribution**: Randomly edits 1 to N sentences (where N = # paraphraseable sentences)
- **Random paraphraser mixing**: Each edited sentence uses random model
- **Span-clipping**: Clips completion right after last edited sentence

**Key innovations:**

1. **Position-based replacement** (not global string replace):
   - Handles duplicate sentences correctly
   - Only replaces specific occurrences we select

2. **Non-paraphraseable preservation**:
   - Pure punctuation (---, $$) kept unchanged
   - Only edits normal prose and markdown headers

3. **Span-clipping** (critical for strong signal):
   - Captures activations at moment of detection
   - Clips right after last edited sentence
   - Avoids dilution from post-recovery text

**Output:** `data/off_policy.json` with `text_clipped` and `text_full`

### 4. Extract Vector
```bash
python 04_extract_vector.py \
    --output artifacts/vector.pt \
    --layers 18 19 20 ... 35  # Default: second half
```

**What it does:**
- Loads model and computes activations for on-policy and off-policy text
- Uses **clipped versions by default** (captures detection moment)
- Computes mean-difference vector: `vector = mean(on_policy) - mean(off_policy)`
- Evaluates with Cohen's d and balanced accuracy

**Key parameters:**
- `--use-full`: Use full completions instead of clipped (for comparison)
- `--layers`: Specific layers to extract (default: layers 18-35)

## Results

### Clipped vs Full Comparison

**Span-Clipped (Default, 200 on / 2000 off samples):**
```
Layer 35: Cohen's d = 2.77, Balanced accuracy = 89.3%
Layer 34: Cohen's d = 1.63, Balanced accuracy = 92.8%
Layers 18-29: Cohen's d ≈ 0.8, Balanced accuracy ≈ 65–70%
```

**Full Completions (with --use-full):**
```
Layer 35: Cohen's d = 0.41, Balanced accuracy = 60.2%
```

**Key Finding:** Span-clipping boosts separability roughly **6.7×** (Cohen's d) by capturing activations at the last edited sentence.

### Dataset Statistics

- **40 prompts** across 5 reasoning categories
- **200 on-policy rollouts** (all usable)
- **2,000 off-policy variants** (10 per rollout)
- **6,821 unique sentences** paraphrased
- **20,463 total paraphrases** (3 per sentence)
- **100%** sentences have all 3 paraphrases

### Edit Distribution

Uniform distribution across edit counts (1-75 edits per variant):
- Most variants: 1-40 edits
- Ensures vector detects any amount of off-policy content

## Design Principles

### 1. Raw String Storage
- Store complete chat-formatted text with all tokens
- No parsing, no abstractions, minimal metadata
- `prompt_with_template + raw_completion` = exactly what model sees

### 2. Random Paraphraser Mixing
**Without mixing** (style confound):
```
Off-policy = [GPT(s1), GPT(s2), GPT(s3)]  # Consistent GPT style
Vector: "off-policy = coherent paraphrased discourse"
```

**With mixing** (clean signal):
```
Off-policy = [GPT(s1), Claude(s2), DeepSeek(s3)]  # Mixed styles
Vector: "off-policy = sentences feel unnatural" ✓
```

### 3. Span-Clipping for Detection
- Extract activations **right after last edited sentence**
- Captures "just detected off-policy" state
- No dilution from model adjusting/recovering
- Critical for steering applications

### 4. Position-Based Editing
- Track sentence positions (line indices)
- Replace specific occurrences, not all matches
- Handles duplicate sentences correctly
- Preserves non-paraphraseable content

## Advanced Usage

### Extract from specific layers
```bash
# Single layer (strongest signal)
python 04_extract_vector.py --layers 35 --output artifacts/vector_layer35.pt

# Custom range
python 04_extract_vector.py --layers 30 31 32 33 34 35
```

### Use full completions (for comparison)
```bash
python 04_extract_vector.py --use-full --output artifacts/vector_full.pt
```

### Adjust edit distribution
```bash
# More variants per rollout
python 03_create_off_policy.py --variants-per-rollout 20

# Different random seed
python 03_create_off_policy.py --seed 123
```

## Interpretation

**What the vector captures:**
- Distinguishes on-policy (naturally generated) from off-policy (paraphrased) reasoning
- Paraphrases preserve semantics while changing syntax/statistics
- Vector detects syntactic/distributional naturalness

**Layer-wise pattern:**
- Early layers (18-29): Weak separation (d≈0.8, ~70% accuracy)
- Final layers (34-35): Strong separation (d=1.6-2.8, 89-93% accuracy)
- Detection signal strengthens in later layers

**Comparison to Persona Vectors:**
- Similar effect sizes (d≈2-4 for personality traits)
- Same mean-difference methodology
- Comparable signal strength
